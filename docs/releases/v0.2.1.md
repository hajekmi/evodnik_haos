First published release of eVodnik Local Proxy for Home Assistant.

- Local water valve control with device status readback, including while the
  vendor server is unavailable.
- TCP proxying for vendor traffic, with separate local and cloud sessions.
- Raw pulse counter and a persistent water meter reading with a configurable
  starting value in liters, assuming one pulse per liter.
- Native Home Assistant entities and optional MQTT state publication.
- Initial counter snapshot is requested immediately, including on hosts that
  have just booted.

Requires Home Assistant Core 2026.9 or newer. Install through HACS as a custom
repository of type **Integration**, then restart Home Assistant Core and add
**eVodnik** under **Settings → Devices & services**. Enter deployment endpoints
in the integration configuration.

Validation uses 60 automated tests with local simulators, Ruff, official
hassfest, and HACS checks. Physical firmware acceptance and mechanical valve
position verification remain pending; see the
[device handover](https://github.com/hajekmi/evodnik_haos/blob/v0.2.1/docs/validation.md).
